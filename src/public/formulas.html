หม้อแปลงดูที่ kVA, ตู้ EV ดูที่ kW

ตู้ EV ระบุกำลังเป็น kW เพราะเป็นกำลังจริงที่จ่ายให้รถ แต่หม้อแปลงรับภาระเป็น kVA หรือ apparent power ดังนั้นระบบต้องใช้ Power Factor แปลง kW เป็น kVA ก่อนตรวจว่าโหลดเกินขีดจำกัดหรือไม่

Dashboard input -> MVA, Limit, PF CSV input -> Base %, Active Chargers Output -> kVA, kW, % กำลังที่เหลือ

Parameter บน Dashboard ใช้ทำอะไร

ตัวแปรเดียวกับที่ใช้ใน code
พิกัดหม้อแปลง (MVA) transformer_mva

พิกัด apparent power ของหม้อแปลง เช่น 30 MVA หมายถึงหม้อแปลงรองรับได้ 30,000 kVA

transformer_kVA = transformer_mva x 1000
ขีดจำกัดโหลด (%) limit_percent

ค่าที่กำหนดว่าหม้อแปลงควรใช้งานไม่เกินกี่เปอร์เซ็นต์ เช่น 80% ของ 30,000 kVA = 24,000 kVA

load_limit_kVA = transformer_kVA x limit_percent / 100
Power Factor power_factor

ใช้แปลงระหว่าง kW และ kVA โดย PF = P / S ถ้า PF ต่ำ โหลด kVA ที่หม้อแปลงเห็นจะสูงขึ้น

ev_load_kVA = ev_load_kW / power_factor
Base Load (%) base_load_percent

มาจาก CSV และแทนโหลดพื้นฐานของพื้นที่ เช่น บ้านพักอาศัย อาคาร หรือโหลดอื่นที่ใช้หม้อแปลงร่วมกัน

base_load_kVA = transformer_kVA x base_load_percent / 100
จำนวนตู้ที่ใช้งาน active_50kW, active_150kW

จำนวนตู้ที่กำลังมีรถชาร์จ ณ time slot นั้น ใช้คูณกับ rated power ของตู้เพื่อหา EV load

ev_load_kW = Σ(active_size x size_kW)
ความเร็วจำลอง interval_ms

กำหนดว่า backend จะอ่านข้อมูลจาก Supabase ทุกกี่มิลลิวินาที ไม่มีผลต่อสูตรไฟฟ้า

1 record / interval_ms

แปลงพิกัดหม้อแปลง

หม้อแปลงระบุพิกัดเป็น MVA จึงแปลงเป็น kVA เพื่อใช้เทียบกับโหลดรวม

transformer_kVA = transformer_MVA x 1000
2

หา Base Load

Base load เป็นโหลดพื้นฐานที่มีอยู่แล้วก่อนรวมโหลดจาก EV

base_load_kVA = transformer_kVA x base_load_percent / 100
3

หา EV Load

ตู้ EV คิดเป็น kW ก่อน แล้วแปลงเป็น kVA ด้วย PF เพื่อเทียบกับหม้อแปลง

ev_load_kW = Σ(active_size x size_kW)
ev_load_kVA = ev_load_kW / PF
4

รวม P และ Q

ระบบใช้ power triangle เพื่อรวมโหลดจริงและโหลดรีแอคทีฟ

sinφ = √(1 - PF²)
total_P = base_kW + ev_kW
total_Q = base_kVAr + ev_kVAr
total_S = √(total_P² + total_Q²)
5

ตรวจสถานะ

โหลดรวมที่ใช้ตรวจหม้อแปลงคือ total_S หน่วย kVA

loading% = total_S / transformer_kVA x 100
if loading% > limit -> OVERLOAD
else if loading% > 70 -> WARNING
6

ลดเป็น % แล้วรักษาขั้นต่ำ 12 kW

หางบ EV ที่เหลือ แล้วลดกำลังตามสัดส่วนพิกัดเท่ากันก่อน ถ้ากลุ่มใดต่ำกว่า 12 kW ให้ตรึงที่ขั้นต่ำและแบ่งงบที่เหลือใหม่ตามสัดส่วนพิกัดของกลุ่มที่ยังลดได้ ทำซ้ำจนทุกกลุ่มถึงข้อจำกัดที่เหมาะสม

B = max(0, (load_limit_kVA - base_kVA) × PF)
D = Σ(active × rated_kW)
r0 = min(1, B / D)  # ถ้า D = 0 ใช้ 1
ผลรอบแรก = rated_kW × r0
ตรึงกลุ่มที่ต่ำกว่า 12 kW ไว้ที่ 12
r = งบที่เหลือ / Σ(active × rated ของกลุ่มที่เหลือ)
remaining_percent = กำลังสุดท้าย / rated_kW × 100
reduction_percent = 100 - remaining_percent

ถ้า B < Σ(active × 12) จะจัดสรรให้ทุกตู้ถึงขั้นต่ำโดยยังอยู่ใน limit ไม่ได้ ระบบแสดงส่วนที่ยังเกินและไม่เปลี่ยนจำนวน active อัตโนมัติ

ขอบเขตของแบบจำลอง

ขั้นต่ำ 12 kW เป็นกติกาการทดลอง ไม่ใช่ขั้นต่ำสากลของรถทุกคัน โมเดลใช้ PF ร่วมและยังไม่คิดการสูญเสีย (η = 1) จึงยังไม่ได้แยกกำลัง AC ขาเข้ากับ DC ขาออก ไม่มี SOC และยังไม่เชื่อมผลไป MATLAB ถ้าใช้ตู้พิกัดต่ำกว่า 12 kW จะจำกัดตามพิกัดและแจ้งว่าตู้กลุ่มนั้นรองรับขั้นต่ำนี้ไม่ได้

ทำไม Dashboard แสดง Base/Total เป็น kVA?

เพราะพิกัดหม้อแปลงเป็น MVA/kVA การตรวจว่าเกินพิกัดหรือไม่ต้องดู apparent power S ไม่ใช่ active power P เพียงอย่างเดียว

ทำไม EV ยังเป็น kW?

พิกัดตู้ เช่น 50 kW หรือ 150 kW ใช้เป็นความต้องการกำลังชาร์จตั้งต้น ในโมเดลนี้ยังไม่คิดการสูญเสียตู้ จึงใช้ค่า kW เดียวกันคำนวณโหลด EV ฝั่งหม้อแปลง

ทำไม PF สำคัญ?

ที่ EV load kW เท่ากัน ถ้า PF ต่ำลง ค่า kVA จะสูงขึ้น ทำให้หม้อแปลงรับภาระมากขึ้นและเข้าใกล้ Overload เร็วขึ้น
