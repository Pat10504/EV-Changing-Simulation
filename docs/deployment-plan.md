# แผนนำระบบจำลองสถานีชาร์จ EV ขึ้นออนไลน์

เป้าหมายสำหรับการนำเสนอกลางเดือนธันวาคม 2026 คือปิด MacBook แล้วเปิด Dashboard จากเครื่องของอาจารย์ เลือกเวลา 18:55 และดูผลวงจรของตู้ตัวแทน 50 kW ก่อนระบบเดินไป 19:00

## ระบบแต่ละส่วนอยู่ที่ไหน

| ส่วน | หน้าที่ |
|---|---|
| GitHub · `main` | เก็บรุ่นที่จะนำไป deploy |
| Railway | รันเว็บ Node.js จัดสรรกำลัง จัดคิวงาน MATLAB และให้ผู้ใช้เปิดผลย้อนหลัง |
| Supabase · PostgreSQL | เก็บทะเบียนตู้ใน `chargers` และโหลดราย 5 นาทีใน `load_patterns` |
| AWS EC2 | รัน Python, MATLAB และโมเดล `DCFastCharger` บนเครื่องเดียวกัน ผู้สาธิตใช้ Remote Desktop เปิดวงจรและ Scope ใน MATLAB session ที่รับงาน |

ในโหมด MATLAB เมื่อแถวที่เลือกมีตู้ 50 kW ทำงาน Railway จะส่งกำลังเป้าหมายให้ EC2 รอและบันทึกผลของแถวนั้น แล้วจึงส่งแถวถัดไป แถวที่ไม่มีตู้ตัวแทนทำงานจะถูกข้ามตามกติกาเดิม โหมดจัดสรรพลังงานและหน้าอุณหภูมิทำงานได้ขณะ EC2 ปิดอยู่

## ขั้นดำเนินการและเกณฑ์ตรวจรับ

- [ ] **1. รวมรุ่นที่จะนำเสนอ** นำหน้าอุณหภูมิ A–D และภาพ IEC เข้า `main` ตรวจว่า Dashboard หน้าอุณหภูมิ และไฟล์วงจรอยู่ใน commit ที่จะ deploy รันชุดทดสอบและบันทึกรหัส commit ที่ผ่าน
- [ ] **2. นำเว็บขึ้น Railway** เชื่อม repo กิ่ง `main` ใช้ `npm start` และตั้ง `SUPABASE_URL` กับ `SUPABASE_SERVICE_ROLE_KEY` ในตัวแปรฝั่งเซิร์ฟเวอร์ จำกัดการสั่งรัน อัปโหลด และล้างข้อมูลไว้ที่ผู้สาธิต ตรวจจากมือถือว่าชุดข้อมูลสาธิตมี 2 ขนาดตู้และ 288 ช่วงเวลา เลือก 18:55 แล้วได้ผลจัดสรร และเปิด `/thermal` ได้เมื่อ EC2 ปิดอยู่
- [ ] **3. พิสูจน์วงจรบน EC2** ตรวจสิทธิ์ AWS Free Plan และสิทธิ์ MATLAB, Simulink, Simscape และ Simscape Electrical สำหรับคลาวด์ เปิดโมเดลผ่าน Remote Desktop แล้วรันหนึ่งรอบ แชร์ session `EVChargingLab` และให้ Python อ่านแรงดัน กระแส และกำลังได้ บันทึกค่าตั้ง ผล และเวลาที่ใช้ต่อรอบ
- [ ] **4. เชื่อม Railway กับ EC2** ตั้งปลายทางของ Python ได้ทั้งโหมดทีละรอบและโหมดอัตโนมัติ ใช้การเชื่อมต่อที่เข้ารหัสและยืนยันสิทธิ์บริการ เก็บผลชุดทดลองใน Railway Volume ที่ `/app/runtime-data` ตรวจว่าแถว 18:55 แสดงกราฟกระแสเป้าหมายเทียบกับกระแสที่วงจรจ่ายก่อนส่ง 19:00 และเปิดผลเดิมได้หลังรีสตาร์ตเว็บ
- [ ] **5. ซ้อมจากเครื่องภายนอก** ปิด MacBook แล้วกดรันจากเบราว์เซอร์อีกเครื่อง ตรวจว่าเมื่อ EC2 พร้อมจะได้ผลจาก MATLAB จริง เมื่อ EC2 ออฟไลน์คิวจะแจ้งสถานะและพักที่แถวที่รอ ส่วนกราฟโหลดและผลย้อนหลังยังเปิดได้
