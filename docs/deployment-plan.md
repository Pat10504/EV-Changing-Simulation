# แผนนำระบบจำลองสถานีชาร์จ EV ขึ้นออนไลน์

เป้าหมายสำหรับการนำเสนอกลางเดือนธันวาคม 2026 คือปิด MacBook แล้วเปิด Dashboard จากเครื่องของอาจารย์ เลือกเวลา 18:55 และดูผลวงจรของตู้ตัวแทน 50 kW ก่อนระบบเดินไป 19:00

## ระบบแต่ละส่วนอยู่ที่ไหน

| ส่วน | หน้าที่ |
|---|---|
| GitHub · `main` | เก็บรุ่นที่จะนำไป deploy |
| Railway | รันเว็บ Node.js จัดสรรกำลัง จัดคิวงาน MATLAB และให้ผู้ใช้เปิดผลย้อนหลัง |
| Supabase · PostgreSQL | เก็บทะเบียนตู้ใน `chargers` และโหลดราย 5 นาทีใน `load_patterns` |
| AWS EC2 | รัน Python, MATLAB และโมเดล `DCFastCharger` บนเครื่องเดียวกัน ผู้สาธิตใช้ Remote Desktop เปิดวงจรและ Scope ใน MATLAB session ที่รับงาน |

ในโหมด MATLAB เมื่อแถวที่เลือกมีตู้ 50 kW ทำงาน Railway จะส่งกำลังเป้าหมายให้ EC2 รอและบันทึกผลของแถวนั้น แล้วจึงส่งแถวถัดไป แถวที่ไม่มีตู้ตัวแทนทำงานจะถูกข้ามตามกติกาเดิม โหมดจัดสรรพลังงานและหน้าอุณหภูมิทำงานได้ขณะ EC2 ปิดอยู่

## ตัวเชื่อม MATLAB บน Windows EC2

Railway รับการเชื่อมต่อขาออกจาก EC2 ผ่าน HTTPS (WebSocket) ตัวเชื่อมรับเฉพาะการตรวจสถานะ ส่งงานวงจร และอ่านผลตามรหัสงาน จากนั้นเรียก Flask ที่ `127.0.0.1:5050` ภายใน EC2 ใช้กฎ RDP เดิมสำหรับเปิดหน้าจอ Windows ได้

1. ตั้ง `MATLAB_WORKER_TOKEN` เป็นค่าสุ่มอย่างน้อย 32 ตัวอักษรใน Railway Variables ใช้เว็บหนึ่ง replica สำหรับคิวและตัวเชื่อม
2. บน EC2 เปิด MATLAB แล้วแชร์ `EVChargingLab` เปิด `web_app.py` ใน Python environment ของวงจร
3. วาง `railway_worker.py`, `requirements-worker.txt` และ `worker-config.json` ไว้ในโฟลเดอร์เดียวกัน JSON มีฟิลด์ `url` (HTTPS origin ของ Dashboard) และ `token` (ค่าเดียวกับ Railway) เก็บไฟล์ตั้งค่าเฉพาะผู้ดูแล EC2
4. ใช้ Python ของวงจรรัน `-m pip install -r requirements-worker.txt` จากโฟลเดอร์ตัวเชื่อม แล้วรัน `railway_worker.py` เมื่อเชื่อมได้จะขึ้น `Connected to Railway` เปิดตัวเชื่อมค้างไว้ใน Windows session เดียวกับ MATLAB และ Flask
5. เข้าระบบที่ Dashboard เลือกโหมด MATLAB ทดสอบ 18:55–19:00 ห่าง 5 นาที ตรวจผล P, V, I ทั้งสองแถว เวลาที่แถวสองเริ่มต้องเท่ากับหรือหลังเวลาที่แถวแรกเสร็จ ถ้าขาดการเชื่อมต่อให้เช็กสถานะแล้วกดทำต่อ ระบบตรวจรหัสงานเดิมก่อนส่งงานใหม่

ตัดการเชื่อมต่อ Remote Desktop ได้โดยใช้ Disconnect หาก Windows รีสตาร์ตหรือ Sign out ให้เปิดและแชร์ MATLAB พร้อมเปิด Flask และตัวเชื่อมใหม่ เมื่อรันจาก Mac แบบ local โดยเว้นตัวแปรตัวเชื่อมว่าง Node จะเรียก Flask ในเครื่องตามเดิม
